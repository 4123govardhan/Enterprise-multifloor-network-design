# Network Topology

This folder contains the topology diagram for the Enterprise Multi-Floor Network Design and Implementation project.

The network includes:
- Three routers connected through serial links
- Three floor switches
- Separate VLANs for departments
- Router-on-a-stick inter-VLAN routing
- DHCP and OSPF routing
- Wireless access points and end devices

The Packet Tracer project file is available in the root repository.
