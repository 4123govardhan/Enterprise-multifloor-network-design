# Network Testing and Verification

This folder documents the verification and troubleshooting tests performed on the enterprise multi-floor network.

## Planned Verification Areas

1. **OSPF:** Check neighbor adjacency and routing table entries.
2. **VLANs and Trunking:** Verify VLAN assignments and trunk links.
3. **DHCP:** Check dynamic IP address allocation.
4. **Port Security:** Verify sticky MAC address learning on the Test-PC port (Fa0/2) of the third-floor switch.
5. **Connectivity:** Test communication between devices and VLANs using ping.
6. **SSH:** Verify remote access to routers.

Verification screenshots and actual test results will be added as they are collected.
